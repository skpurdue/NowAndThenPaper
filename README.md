# The Now and Then: Integrating Current and Historical Data in Small Multiple Time Series Visualization

These are the supplemental materials for our paper.

Code has been included for the generation of all images seen by participants and the analysis of results. Anonymous data from participants has also been included. Pdfs of the survey implements have been included as well. Complete image repositories are only available through the OSF due to size restrictions. The OSF repository can be found here: https://osf.io/wzf6a

Stimuli images were saved at a larger size than shown to participants. The images were sized down in Qualtrics to fit on the same page. Resizing the images upon generation led to a loss in fidelity, so we used the higher quality images and made them smaller in that interface. Images in Qualtrics were sized to 850 x 546px.

Code may use some discrepant language due to changes in naming convention prior to the submission of this paper. "Ident" or "Identification" generally refers to our Find tasks. "Est" or "Estimation" generally refers to our Lookup tasks.

There may be some lingering references to "situated viz" and this is due to the origin case of the project, prior to reframing.
